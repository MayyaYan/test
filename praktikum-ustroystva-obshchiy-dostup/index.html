    Задание 5 · 25 минут · 20 баллов

    Исследование своего компьютера

    Выполните действия на компьютере, за которым работаете, и заполните поля. Задание оценивает преподаватель: по 1 баллу за каждое верно заполненное поле. Ничего не удаляйте и не отключайте без разрешения преподавателя.

    Где искать сведения

    1. Win + R → devmgmt.msc. Разверните «Сетевые адаптеры» → свойства адаптера → вкладки «Драйвер» и «Ресурсы». Меню «Вид» → «Ресурсы по типу» → «Запрос на прерывание (IRQ)».
    2. Ctrl + Shift + Esc → «Процессы» (сортировка по столбцу «Память») и «Автозагрузка» (столбец «Влияние на запуск»).
    3. Win + R → services.msc → служба «Диспетчер печати»: тип запуска и состояние.
    4. Win + R → perfmon → «Средства наблюдения» → «Системный монитор». Счётчик «% загруженности процессора» уже добавлен; через 1–2 минуты прочитайте значение «Среднее» под графиком.
    5. Командная строка → net share: список общих ресурсов. Или Win + R → fsmgmt.msc → «Общие ресурсы».
    6. Если есть права администратора: создайте папку Practice_Фамилия, свойства → «Доступ» → «Расширенная настройка» → «Открыть общий доступ». Разрешения: «Все» — «Чтение». Запишите сетевой путь.
    7. Win + R → eventvwr.msc → «Журналы Windows» → «Система» → «Фильтр текущего журнала»: уровни «Критический» и «Ошибка», за последние 24 часа.
    8. Win + R → perfmon /rel: Монитор стабильности системы.

    Работаете на Linux? Устройства — lspci -k и lsusb, ресурсы — top и free -h, службы — systemctl list-units --type=service, журнал — journalctl -p err -b, общие папки — Samba, smbclient -L localhost.
