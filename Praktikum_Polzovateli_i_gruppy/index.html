    Команды net

    За каждую верную команду — 2 балла. Команды на компьютере не выполняйте: часть из них удаляет учётные записи.

    Справка: синтаксис команд
    КомандаЧто делает
    net user имя пароль /addсоздаёт локальную учётную запись
    net user имя /deleteудаляет учётную запись
    net user имя /active:noотключает учётную запись (/active:yes — включает)
    net user имя /logonpasswordchg:yesтребует сменить пароль при следующем входе
    net localgroup группа /addсоздаёт локальную группу
    net localgroup группа имя /addдобавляет пользователя в группу (/delete — исключает)
    net accounts /minpwlen:Nзадаёт минимальную длину пароля для всех учётных записей
    net accounts /lockoutthreshold:Nзадаёт порог блокировки после N неудачных попыток входа

    Задание 3 · 25 минут · 20 баллов

    Симулятор групп и прав

    Правила расчёта итогового доступа
    • Уровни доступа по силе: Нет доступа < Чтение < Изменение < Полный доступ.
    • Сотрудник входит в группы по своей должности. Руководитель отдела входит и в группу отдела, и в группу руководства.
    • Если человек состоит в нескольких группах, их разрешения складываются: действует большее.
    • Явный запрет сильнее любого разрешения.
    • Отключённая учётная запись не может войти в систему, значит доступа нет ни к чему.
    • Учётную запись уволенного сотрудника сначала отключают, удаляют позже, после сохранения его данных.
    • Если наследование отключено и унаследованные разрешения удалены, действуют только явно заданные разрешения вложенной папки.

    Задание 4 · 15 минут · 12 баллов

    Политика паролей

    На компьютере вашего варианта настроена политика паролей. Определите, примет ли Windows каждый из шести паролей при смене пароля пользователя. Каждый ответ — 2 балла.

    Справка: требования сложности Windows
    • Длина пароля должна быть не меньше минимальной — это правило действует всегда.
    • Если требования сложности включены, пароль должен содержать символы хотя бы трёх категорий из четырёх: заглавные буквы, строчные буквы, цифры, специальные символы (! # % @ и т. п.).
    • При включённой сложности пароль не должен содержать имя входа пользователя (без учёта регистра).
    • Если сложность отключена, проверяется только длина.

    Задание 5 · 25 минут · 20 баллов

    Учётные записи своего компьютера

    Выполните действия на компьютере, за которым работаете, и заполните поля. Задание оценивает преподаватель: по 1 баллу за каждое верно заполненное поле. Создавайте и удаляйте только тестовую учётную запись test_фамилия и только с разрешения преподавателя.

    Где искать сведения

    1. Откройте командную строку: Win + R → cmd. Выполните whoami и net user.
    2. net user Администратор и net user Гость — строка «Учётная запись активна». В английской Windows — Administrator и Guest.
    3. net user %USERNAME% — последний вход, срок действия пароля, членство в локальных группах.
    4. whoami /groups, net localgroup, net localgroup Администраторы, net localgroup Пользователи.
    5. net accounts — минимальная длина пароля, срок действия, порог блокировки.
    6. icacls "%USERPROFILE%\Documents" — разрешения на папку «Документы». Буквы: F — полный доступ, M — изменение, RX — чтение и выполнение, (I) — разрешение унаследовано.
    7. Если есть права администратора (командная строка «Запуск от имени администратора»): net user test_фамилия * /add → net localgroup Пользователи test_фамилия /add → net user test_фамилия /active:no → net user test_фамилия /delete. После каждой команды проверяйте результат через net user test_фамилия.

    Работаете на Linux? Пользователи — cat /etc/passwd и id, группы — groups и getent group sudo, политика паролей — chage -l $USER, разрешения — ls -l ~; создание — sudo useradd -m test_фамилия, блокировка — sudo usermod -L, удаление — sudo userdel -r.
