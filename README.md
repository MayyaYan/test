# Интерактивная практическая работа: ОС и аппаратное обеспечение

**Тема:** драйверы устройств, оперативная память, ввод-вывод данных, обработка прерываний.

**Продолжительность:** 90 минут. Таймера нет.

## Как открыть

- Откройте `index.html` в браузере. Работа не требует интернета, установки ПО, Python и учётной записи.
- Для размещения в МЭШ загрузите ZIP-архив, содержащий `index.html` в корне.
- Для GitHub Pages используйте `index.html` в корне репозитория или отдельной папке в зависимости от настроек публикации.

## Содержание

- Диагностика драйвера принтера: 25 баллов.
- Интерактивная RAM-модель (first-fit, 16 блоков × 32 МБ), фрагментация и вопросы: 25 баллов.
- Механизмы I/O: прерывания, DMA, буферизация, очередь печати: 25 баллов.
- Восстановление цепочки обработки IRQ и анализ: 25 баллов.
- Итоговая проверка с оценкой по шкале 2–5, загрузка отчёта HTML и результатов CSV для Excel.

**Оценки:** 85–100 = «5», 70–84 = «4», 50–69 = «3», менее 50 = «2».

**Конфиденциальность:** данные ФИО, группы, ответов и экспериментов сохраняются только в localStorage браузера и не отправляются на сервер. Чтобы передать результат преподавателю, студент должен скачать файл отчёта и отправить его обычным способом. Открытые выводы требуют ручной проверки преподавателем.

**Примечание по модели памяти:** для демонстрации фрагментации используется непрерывное выделение first-fit, а не страничное управление памятью современных ОС. Вопросы отдельно проверяют понимание виртуальной памяти.
