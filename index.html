Задание для специалиста технической поддержки

Практическая ситуация: в компьютерном классе необходимо исследовать работу учебной станции. Принтер периодически не определяется, пользователю не хватает ресурсов, передача файлов замедляется, а устройства передают события ОС. Ты — специалист, который должен выбрать правильные способы диагностики.

Работа состоит из четырёх лабораторных блоков. Используй симулятор выделения памяти, принимай инженерные решения, выстраивай порядок действий и объясняй результаты в отчёте. Для выполнения не нужны Python, Интернет или специальные права на компьютере.

Блок 2. Управление RAM · 25 баллов

Рассмотри учебную модель непрерывного выделения памяти методом first-fit («первый подходящий свободный участок»). Память условно разделена на 16 блоков по 32 МБ — всего 512 МБ.

Ограничение модели: это наглядный пример внешней фрагментации при непрерывном выделении. Реальные современные ОС обычно используют виртуальную память и страницы; они не выделяют все данные процессов только таким способом.

Блок 3. Ввод-вывод · 25 баллов

Учебная станция одновременно печатает задания, копирует большой файл, обрабатывает нажатия клавиатуры и принимает поток данных. Твоя задача — выбрать наиболее подходящий механизм для каждой ситуации.
